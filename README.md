# Mohamed Rusaick Mufthi — Cyber Security & Network Security Portfolio

A modern, production-ready personal portfolio website built with Next.js 15, React 19, TypeScript, Lenis, and Tailwind CSS v4.

This portfolio is strictly positioned toward:
**Software Engineering foundation → Computer Networks → Network Security → Cyber Security**

---

## 🚀 Commands

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build Video & Image Assets
```bash
python scripts/build-hero-assets.py
```

### Production Build & Linting
```bash
npm run build
```

### Production Preview
```bash
npm run start
```

---

## 🛠️ Technology Stack
* **Framework:** Next.js 15 (App Router)
* **Library:** React 19
* **Styling:** Tailwind CSS 4
* **Smooth Scroll:** Lenis (`lenis`)
* **Typography:** Inter Tight, Instrument Serif, JetBrains Mono (Next.js font self-hosted)
* **Language:** TypeScript
* **Icons:** Lucide React

---

## 📑 Core Sections Implemented
1. **Hero Section:** Intro video player (`intro.mp4`), ghost name backdrop, circular sound toggle, viewport auto-pause/resume.
2. **About (Security Profile):** Interactive flippable ID card with front/back focus areas and quick facts.
3. **Security Focus:** 4-stage progression path from Software Engineering to Cyber Security.
4. **Skills (The Security Stack):** Categorized skills grid with index badges, symbols, and security highlights.
5. **Projects (Security & Technical Work):** Featured XSS Attack Detection ML research with interactive Streamlit SOC triage mockup & expanding gallery.
6. **Certifications (Always Learning):** Numbered index table with ink-flooding hover effect.
7. **Experience & Education:** Chronological timeline combining degrees, BCAS IT Society leadership, and academic references.
8. **Achievements:** Verified benchmark metrics (99.81% XSS accuracy, 15 members led, 0.915 R² score).
9. **Contact & Footer:** Interactive email copy button (`Copied ✓`), phone `tel:` link, rotating badge, and back-to-top navigation.
